Вариант 10

Курсы и преподаватели

Основная таблица courses содержит поля:

ПолеТипНазначение
idINTEGER PRIMARY KEYИдентификатор курса
course_nameTEXT NOT NULLНазвание курса
teacher_idINTEGER NOT NULLВнешний ключ преподавателя
creditsREAL NOT NULLПоложительное количество кредитов

Имя преподавателя хранится в таблице teachers. В таблице курсов сохраняется только teacher_id; для отображения имя преподавателя получается через SQL JOIN.

CRUD

Маршруты сервера

GET /api/courses

Получить список курсов.

GET /api/courses?teacher_id=3

Получить курсы выбранного преподавателя.

POST /api/courses

Создать курс. Название и преподаватель обязательны, кредиты должны быть положительными.

PUT /api/courses/:id

Изменить курс по идентификатору.

DELETE /api/courses/:id

Удалить курс по идентификатору.

Структура

Разделение ответственности

server.js запускает Express и подключает маршруты. Файлы из папки routes обрабатывают HTTP-запросы. Модули из database создают подключение к SQLite и содержат функции для работы с таблицами. Клиентская часть находится в папке public.
